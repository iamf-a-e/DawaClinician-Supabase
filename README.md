# DawaClinician Mobile App

A new Flutter project by **Dawa Health**.

---

## 🩺 Overview

**DawaClinician** is the mobile companion app for healthcare providers within the Dawa Health ecosystem.  
It enables clinicians to manage patient encounters, review AI-generated triage summaries, and deliver timely care from their mobile devices.

### Core Features

- 👩🏾‍⚕️ **Patient Management:** View assigned patients and their health history  
- 🧠 **AI Triage Review:** Access and validate AI-generated summaries and insights  
- 🗓️ **Appointments:** Manage upcoming consultations and schedules  
- 💬 **Chat Interface:** Communicate with patients and support follow-up care  
- 📋 **Encounter Records:** Record clinical notes, diagnoses, and prescriptions
